# Задание 4. Асинхронный JavaScript

Страница «Выбор даты и времени» получает данные с имитационного сервера.

## Запуск
```
npm install
npm run dev
```
Открыть http://localhost:3000

## Эндпоинты
- `GET /api/booking/today` -> `{ day, month, year }` (месяц с нуля)
- `GET /api/slots?day=17&month=9&year=2026` -> `{ date, slots }`, слот: `{ time, available }`

## Проверка сценариев
1. Открытие страницы: «Загрузка…», затем календарь с сегодняшним днём.
2. Клик по дню: «Загрузка слотов…», затем слоты.
3. Ошибка: выбрать 13 число (сервер отвечает 500, см. `ERROR_DAY` в `server/server.js`), появится сообщение и кнопка «Повторить».
